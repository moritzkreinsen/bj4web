# Licensing

BJ4Web is an independent adaptation. The original BlueJ and Greenfoot license text and Classpath Exception are retained in LICENSE.txt. New BJ4Web sources are distributed under that same framework. The web worker uses unmodified upstream BJMap. The desktop source tree and assets retain their original notices. See THIRD_PARTY_NOTICES.md for the web prototype's toolchain.

No desktop JARs, fonts, artwork, audio, example collections or installers are included in the web frontend. Before publishing a binary distribution, inventory its exact contents and verify each bundled item's license and required notices against the desktop documentation. The initial source audit does not establish asset-by-asset redistribution rights for a future browser bundle.
